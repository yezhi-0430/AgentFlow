# 当前限制

本项目目前是本地开发版本。文档只承诺已经接通的功能，原始设计中的部分能力仍未实现。

## 数据与服务

- 工作流、消息和模型连接保存在后端内存中；重启后清空，没有数据库、工作流导入导出或多用户隔离。
- 后端没有登录鉴权，CORS 配置面向本地开发，不适合直接暴露到公网。
- 工作流密钥在后端对象中保留至工作流删除或进程退出；前端不持久化密钥。
- 不同浏览器标签页可能同时操作同一工作流；服务端尚未提供完整的并发控制。

## 执行模式

- 顺序执行已接通任务、步骤、状态与消息历史。
- 并行执行目前缺少完整的步骤进度与消息历史记录。
- 层次模式还没有完整执行分支；辩论模式的 API 创建路径也未补全角色与步骤配置。
- 暂停、停止和单步执行尚未形成完整的可取消任务控制；页面没有宣称这些操作已经可用。
- Agent 调用失败时，旧引擎可能将错误文本传给后续 Agent。前端会将这种执行标记为异常，但服务端的失败即停机制仍待完善。
- 顺序执行采用通用 worker 提示词，后续 worker 可能要求进一步说明任务；复杂内容生产仍需专门的角色与交接设计。

## 模型

- 优先使用 OpenAI 或 OpenRouter 的对应连接。OpenRouter 的 Key 不能直接提交给 OpenAI 官方接口。
- 模型选项是配置快照，服务商可变更模型可用性、权限与名称，应以自己的服务商控制台为准。
- 当前 Claude 适配器走 OpenAI 兼容接口，默认地址是 OpenRouter；它不等同于已完成的 Anthropic 原生 API 接入。需要 Claude 时，建议通过 OpenRouter 选择对应模型。
- 本地模型尚未接入，创建页面会提示暂不支持。

这些限制已在整理时记录，本次没有把清理任务扩展成整个执行引擎的重写。
